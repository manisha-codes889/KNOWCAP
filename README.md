
# KNOWCAP
### Smart Employee Knowledge Handover System

## About the Project
KNOWCAP is a web-based employee knowledge handover system designed to reduce knowledge loss when an employee leaves an organization or changes roles.

It helps capture employee knowledge, identify knowledge gaps, track pending tasks, and generate structured handover reports.

## Problem Statement
When employees leave an organization, important project information, responsibilities, and ongoing tasks may get lost.

## Our Solution
KNOWCAP provides a structured platform to make the employee handover process easier, organized, and more reliable.

## Key Features
- Employee and Project Details
- Knowledge Interview System
- Knowledge Gap Detection
- Handover Readiness Score
- Risk Level Indicator
- Pending Task Tracker
- Employee Handover Checklist
- Handover Report Generation
- Downloadable Handover Report
- Data Persistence

## Technology Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start using the KNOWCAP application.

## Project Objective
To make employee knowledge transfer structured, accessible, and efficient while reducing the risk of losing important organizational knowledge.
